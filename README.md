# TRUECHOICE MVP 1.0

Deploy-ready React/Vite starter for the TRUECHOICE evidence-led shopping platform.

Included: responsive storefront, real search, products, brands, Evidence Explorer, source links and external purchase links.

Run locally:
1. Install Node.js 20+
2. `npm install`
3. `npm run dev`

Production build:
`npm run build`

Next production step: replace the demo arrays in `src/main.jsx` with a real database/API and add an admin interface. The current company/evidence content is demonstration data and is not a final TRUECHOICE rating.
